# pairwise-loudness-normalization

同一集不同片段响度忽大忽小，响度归一化只算整段平均，安静对白被音乐拉高；积分响度没做门限，长段静音把整体拉低；真峰值限制器只削样本峰值，采样间峰值仍然过载；短时响度窗口固定 3 秒，动作片的爆炸被平滑掉；多声道按声道平均而不是按功率求和，中置对白被低估；采样率转换后响度重新计算，44.1k 与 48k 得到两个目标值；流媒体目标 -14 LUFS 与广播 -23 LUFS 共用一套增益，电视端爆音；元数据写了 loudnessRange 但播放器不读，实际增益仍按旧值；淡入淡出段也参与积分，片头黑场拉低整集；限制器释放时间固定，鼓点密集段出现泵动。media/loudness_normalization.py 是核心，tests/test_loudness_normalization.py 15个红。要修的是：按片段分别归一；积分加绝对门限；真峰值过采样检测；短时窗口自适应；多声道功率求和；采样率无关计算；目标按分发平台；写入并校验元数据；淡入段排除；释放时间自适应。

## 运行

```bash
python -m pytest tests -q
```
